Configuration update for **cpa-deepseek**, compatible with **CLIProxyAPI v8.0.0+**.

### Changes

- Rename the plugin configuration array from `credentials` to `api-keys`. Update configuration parsing, plugin configuration fields, validation messages, examples and both READMEs.
- Use a square DeepSeek icon in the plugin store.

### Configuration migration

Before upgrading, rename `plugins.configs.cpa-deepseek.credentials` to `plugins.configs.cpa-deepseek.api-keys`. The old field is no longer accepted. Keep each entry's `name` and `api-key` unchanged; environment variable expansion remains supported in `api-key` values.

Credential identities remain derived from the API key, so this configuration rename preserves existing credential identities and stored host state. CPA management endpoints under `/v8/management/credentials` are unchanged.

### Installation and compatibility

- Requires CPA v8.0.0+ with native plugins enabled. The plugin ID is `cpa-deepseek`; the provider and default model prefix are `deepseek`.
- Download `cpa-deepseek_0.1.2_<goos>_<goarch>.zip` for the operating system and architecture running CPA, verify it against `checksums.txt`, and copy the root-level dynamic library into CPA's plugin directory.
- ZIPs are available for Linux amd64/arm64, macOS amd64/arm64 and Windows amd64. Both READMEs, example configuration, license and icon source notes are included.
- Responses requests require full input history. Independent Files, Search, Fetch and token-counting operations are not implemented.
- Balance is shared by keys belonging to the same DeepSeek account. Live inference requires a valid API key and sufficient balance.
