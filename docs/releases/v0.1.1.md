Packaging update for **cpa-deepseek**, compatible with **CLIProxyAPI v8.0.0+** and the CLIProxyAPI Plugins Store release format.

### Changes

- Publish ZIPs for all five supported platforms: Linux amd64/arm64, macOS amd64/arm64, and Windows amd64.
- Use store-compatible asset names: `cpa-deepseek_0.1.1_<goos>_<goarch>.zip`.
- Place the single target dynamic library at the ZIP root: `cpa-deepseek.so`, `cpa-deepseek.dylib`, or `cpa-deepseek.dll`.
- Provide SHA-256 checksums in `checksums.txt` using sha256sum format.
- Validate archive integrity, library names and layout before creating the release draft.

### Installation

Download the ZIP matching the operating system and architecture **running CPA** and verify it against `checksums.txt`. Extract it and copy the root-level dynamic library into CPA's plugin directory. Both READMEs, the sample configuration, license, and icon source notes are included.

### Compatibility and limits

- Requires CPA v8.0.0+ with native plugins enabled. The plugin ID is `cpa-deepseek`; the provider and default model prefix are `deepseek`.
- Provider behavior and configuration are unchanged from v0.1.0.
- Responses requests require full input history. Independent Files, Search, Fetch, and token-counting operations are not implemented.
- Balance is shared by keys belonging to the same DeepSeek account. Live inference requires a valid API key and sufficient balance.
