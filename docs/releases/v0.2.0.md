Model discovery and protocol dependency update for **cpa-deepseek**, compatible with **CLIProxyAPI v8.0.0+**.

### Changes

- Display the plugin as **DeepSeek** in registration metadata. The plugin ID remains `cpa-deepseek`; the provider and default model prefix remain `deepseek`.
- Fail startup or reconfiguration with `model_discovery_failed` when discovery fails and neither configured models nor a usable cached snapshot is available. Failed reconfiguration preserves the running plugin configuration and catalog.
- Preserve configured and cached model fallbacks when discovery exhausts its timeout by giving credential initialization a separate deadline.
- Report discovery failures by HTTP status, timeout, transport failure or invalid response, without logging API keys or upstream response bodies. Treat empty discovery responses as failures and try the remaining configured keys.
- Log background discovery failures and warn when a changed local model catalog requires a plugin reload to update the host's model list.
- Upgrade apix from v0.1.0 to v0.2.0, including its moego dependency. The public conversion API is unchanged; edited JSON and some SSE payloads may preserve more of the original field order and formatting.

### Upgrade notes and known limits

- Configuration is unchanged from v0.1.3: API key entries use `api-keys[].value`, with optional `name` and environment variable expansion in `value`.
- A deployment with no explicit model declarations now reports an initialization error if discovery is unavailable on its first start. Restore discovery connectivity or configure supported models explicitly before retrying.
- Periodic discovery updates the plugin's local snapshot. Updating CPA's published `/v1/models` list still requires reloading or reconfiguring the plugin. This release contains only plugin-side changes and does not add a host model-refresh extension.
- Responses requests require full input history. Independent Files, Search, Fetch and token-counting operations remain unimplemented.

### Installation

Download `cpa-deepseek_0.2.0_<goos>_<goarch>.zip` for the operating system and architecture running CPA, verify it against `checksums.txt`, and copy the root-level dynamic library into CPA's plugin directory.

ZIPs are available for Linux amd64/arm64, macOS amd64/arm64 and Windows amd64. Both READMEs, example configuration, license and icon source notes are included. Live inference requires a valid DeepSeek API key and sufficient account balance.
