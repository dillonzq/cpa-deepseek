First release of **cpa-deepseek**, a native DeepSeek provider plugin for **CLIProxyAPI v8.0.0+**.

### Features

- Discover official DeepSeek models with optional metadata overrides.
- Support Chat Completions, Responses and Anthropic Messages natively; convert Gemini GenerateContent through apix. All four support streaming.
- Preserve tools, reasoning history and native protocol extensions; support thinking controls and CPA model suffixes.
- Configure multiple named API keys with stable credential identities and CPA-managed selection, rotation, retries and cooldowns.
- Fetch the selected credential's account balance through CPA v8 quota management, with separate CNY/USD summaries.
- Validate static keys through credential refresh; recover a selected credential through CPA's native cooldown reset.
- Cancel upstream requests and streams on disconnect, timeout and plugin shutdown.

### Installation

Download the archive matching the **CPA host's** operating system and architecture:

- Linux: amd64 or arm64 (`.tar.gz`)
- macOS: amd64 or arm64 (`.tar.gz`)
- Windows: amd64 (`.zip`)

Verify your archive against `SHA256SUMS`, extract it, and copy the `.so`, `.dylib` or `.dll` into CPA's plugin directory. Enable the plugin and configure `DEEPSEEK_API_KEY` using the included `config.example.yaml`. See the bundled English or Chinese README for setup and management examples.

### Compatibility and limits

- Requires CPA v8.0.0+ with native plugins enabled. The plugin ID is `cpa-deepseek`; the provider and default model prefix are `deepseek`.
- Responses requests must include full input history; non-empty `previous_response_id` and `conversation` are rejected.
- Independent Files, Search, Fetch and token-counting operations are not implemented.
- Balance belongs to the DeepSeek account; multiple keys for one account share balance and concurrency limits.
- Automated tests use mock upstream servers, including real CPA host loading. Live DeepSeek inference requires separate verification with your own key and account balance.
