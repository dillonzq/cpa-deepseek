Configuration update for **cpa-deepseek**, compatible with **CLIProxyAPI v8.0.0+**.

### Changes

- Rename each API key entry's configuration field from `api-key` to `value`. Update parsing, validation messages, plugin configuration descriptions, examples and both READMEs.
- Reject the old `api-key` field, including entries that also specify `value`. No compatibility alias is provided.

### Configuration migration

Before upgrading, rename `plugins.configs.cpa-deepseek.api-keys[].api-key` to `plugins.configs.cpa-deepseek.api-keys[].value`. Keep the `api-keys` array and each entry's optional `name` unchanged. Environment variable expansion remains supported in `value` only.

Credential identities remain derived from the API key, so this field rename preserves existing credential identities and stored host state.

### Installation and compatibility

- Requires CPA v8.0.0+ with native plugins enabled. The plugin ID is `cpa-deepseek`; the provider and default model prefix are `deepseek`.
- Download `cpa-deepseek_0.1.3_<goos>_<goarch>.zip` for the operating system and architecture running CPA, verify it against `checksums.txt`, and copy the root-level dynamic library into CPA's plugin directory.
- ZIPs are available for Linux amd64/arm64, macOS amd64/arm64 and Windows amd64. Both READMEs, example configuration, license and icon source notes are included.
- Responses requests require full input history. Independent Files, Search, Fetch and token-counting operations are not implemented.
- Balance is shared by keys belonging to the same DeepSeek account. Live inference requires a valid API key and sufficient balance.
