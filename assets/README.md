# Assets / 图标资源

## DeepSeek icon

[`logo.svg`](logo.svg) is an unmodified copy of the blue whale favicon used by
the [official DeepSeek API documentation](https://api-docs.deepseek.com/).

- Official asset: <https://api-docs.deepseek.com/img/favicon.svg>
- Retrieved: 2026-10-28
- Original view box: `0 0 63.1196 46.4033`
- Use: both READMEs display this local SVG. The plugin's `Metadata.Logo` points
  directly to the official asset URL for CPA management clients and the plugin store.

To update the local copy without changing the artwork:

```sh
curl --fail --location https://api-docs.deepseek.com/img/favicon.svg -o assets/logo.svg
```
